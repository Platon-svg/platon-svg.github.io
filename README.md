# Platon – сайт-портфолио (версия 2)

Адаптивный одностраничный сайт-портфолио на HTML, CSS и JavaScript. Проект подготовлен для публикации через GitHub Pages.

## Локальный запуск

Откройте `index.html` в браузере. Для запуска через локальный сервер:

```bash
python -m http.server 8000
```

Перейдите на `http://localhost:8000`.

## Публикация через GitHub Pages

1. Создайте публичный репозиторий в аккаунте `Platon-svg`. Для адреса вида `https://platon-svg.github.io/` имя репозитория должно быть `Platon-svg.github.io`. Если такой репозиторий уже существует, используйте отдельный репозиторий и адрес вида `https://platon-svg.github.io/<имя-репозитория>/`.
2. Загрузите в корень репозитория все файлы сайта: `index.html`, `style.css`, `app.js`, `assets/`, `.nojekyll` и `404.html`.
3. В настройках репозитория откройте **Settings → Pages** и выберите публикацию из ветки `main`, папка `/ (root)`.
4. Дождитесь завершения публикации и проверьте HTTPS-адрес.
5. Откройте опубликованную страницу и нажмите «QR-код сайта» внизу страницы. QR-код сформируется по текущему публичному URL.

## Перед окончательной сдачей

В текущей сборке использован псевдоним `Platon` и ссылка на GitHub `https://github.com/Platon-svg`. Перед публикацией замените демонстрационные контакты в `index.html` и `app.js`:

- `hello@example.com` – на действующий адрес электронной почты;
- `+7 (999) 123-45-67` и `tel:+79991234567` – на действующий номер телефона;
- `https://t.me/` и `https://www.behance.net/` – на свои профили или удалите лишние ссылки.
- `assets/workspace.webp` – замените на собственное фото или фотографию своей работы, если преподаватель требует именно личный фотоматериал. Сейчас это специально сгенерированная иллюстрация рабочего места, а не фотография автора.

## Форма обратной связи

Форма проверяет имя, формат электронной почты и сообщение длиной не менее 10 символов. После проверки она формирует письмо через `mailto:`. Браузер передаёт его почтовому приложению пользователя, но сам сайт не отправляет письмо на сервер. Для автоматического приёма сообщений потребуется внешний обработчик форм или серверная часть.

## QR-код

Генератор использует URL открытой страницы. На опубликованном сайте он создаёт QR-код с публичной ссылкой, который можно сохранить в формате SVG. Локальный QR-код до публикации не следует включать в отчёт.

## Структура

- `index.html` – структура сайта и содержимое четырёх разделов;
- `style.css` – авторские стили и адаптивная сетка;
- `app.js` – мобильное меню, фильтрация галереи, валидация формы и QR-код;
- `assets/` – оригинальная сгенерированная иллюстрация, четыре SVG-концепта, favicon и локальный генератор QR;
- `Отчет_сайт-портфолио_v2.docx` – отчёт к практическому заданию (поля ФИО, группы, ссылки и QR-кода заполняются после персонализации и публикации).

Лицензионная информация находится в `LICENSES.txt`.
