# Platon Robotics — сайт-портфолио

Адаптивный одностраничный сайт-портфолио Карнаухова Платона Сергеевича, начинающего инженера-робототехника.

## Структура
- `index.html` — основная страница сайта;
- `style.css` — стили сайта;
- `app.js` — навигация, валидация формы, генерация QR-кода;
- `assets/` — фотографии, логотип и вспомогательные файлы;
- `404.html` — страница ошибки для GitHub Pages.

## Публикация
Сайт подготовлен для публикации на GitHub Pages из ветки `main`, папка `/(root)`.
Публичный адрес после публикации: `https://platon-svg.github.io/`.
